Real-Time Manga Translator settings

Gemini API key

Stored in this browser's extension storage and sent only to Google's Gemini API. Get one at Google AI Studio.

Finding the manga pages

The first time you use a site, the popup looks for the images with manga panels in them and remembers their dimension. If it can't tell, it asks you to pick the preview that looks like a manga page. If a later chapter uses a different dimension, this happens once more and both are remembered.

Overlay shortcut

Shows or hides the translations on the page. Click the box and press a key combination.
